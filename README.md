# Agri Equilibrium – Agentic AI Software Prototype

by Vishal Vasudeo, October 2026

An executive console for the Maharashtra pilot: demand and supply of sugarcane, tur and soybean across 36 districts, weekly stock-flow balance, oversupply and undersupply flags, and agent recommendations.

Open the live prototype: **https://vishalvasudeo-dev.github.io/agri-equilibrium/**

All figures come from the model's version 3.3 equations run on a synthetic 36-month dataset (October 2023 to September 2026). They do not describe any actual district, season or price.
